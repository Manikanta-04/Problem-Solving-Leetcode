## 📚 Topics Covered

| Topic | Description |
|-------|-------------|
| **Arrays** | Problems involving traversal, manipulation, and searching in arrays |

| **Basic Maths** | Number theory problems — digits, divisors, GCD, prime numbers |
| **Basic Recursion** | Foundational recursive problems to build problem-solving intuition |
| **Binary Search** | Classic and advanced binary search on arrays and answer spaces |

| **Java Basic Input and Output** | Java I/O techniques used in competitive programming |
| **Linked List** | Singly & doubly linked list problems — reversal, cycles, merging |
| **Recursion Pattern** | Advanced recursive patterns like backtracking and divide & conquer |
| **Sorting Techniques** | Bubble, Selection, Insertion, Merge, Quick sort implementations |
| **Strings** | String manipulation, pattern matching, and substring problems |

## 🧠 How to Use This Repo

1. **Browse by topic** — Open the folder that matches the concept you want to practice.
2. **Read the solution** — Each file contains a clean Java solution to the corresponding LeetCode problem.
3. **Understand the approach** — Try to understand the logic before looking at the code.
4. **Practice yourself** — Attempt the problem on [LeetCode](https://leetcode.com/) first, then compare.

## 🌟 Tips for Beginners

- Don't jump straight to hard problems. Start with **Easy → Medium → Hard**.
- Focus on **understanding the pattern**, not memorizing the solution.
- Re-solve problems after a few days to test your retention.
- Always think about **time complexity** and **space complexity**.

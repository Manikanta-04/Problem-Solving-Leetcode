## 📚 Topics Covered

| Topic | Description |
|-------|-------------|

| **Basic Recursion** | Foundational recursive problems to build problem-solving intuition |
| **Binary Search** | Classic and advanced binary search on arrays and answer spaces |

| **Sorting Techniques** | Bubble, Selection, Insertion, Merge, Quick sort implementations |

## 🧠 How to Use This Repo

1. **Browse by topic** — Open the folder that matches the concept you want to practice.
2. **Read the solution** — Each file contains a clean Java solution to the corresponding LeetCode problem.
3. **Understand the approach** — Try to understand the logic before looking at the code.
4. **Practice yourself** — Attempt the problem on [LeetCode](https://leetcode.com/) first, then compare.
